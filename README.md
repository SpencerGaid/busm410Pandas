# BUSM 410 Pandas Project

## About the Project
This repository is the working space for Team Pandas' BUSM 410 semester project. We will use Python and pandas to prepare and analyze data from BigQuery, document our data quality checks, and communicate findings related to improving a current process.

## Introduction
Organizations can use data to understand how their processes are performing and where improvements may be possible. In this project, we will examine data available through BigQuery, assess its quality, and use a reproducible analysis process to identify evidence that can guide process improvement. We will document our methods and checks so readers can follow how we move from data to conclusions.
